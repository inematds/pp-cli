# Módulo 5 — Caso prático: criar CLI para BrasilAPI

⏱️ **30 min** · [← módulo 4](04-criando-cli.html) · [próximo →](06-integracoes.html)

🚧 **Em desenvolvimento.** Vamos construir do zero uma CLI `brasil-api-pp-cli` com:

- CEP (Correios)
- CNPJ (Receita Federal)
- Bancos (Bacen)
- Feriados nacionais
- DDD → cidades
- Cache local em SQLite (consultar offline)
- Comandos compostos: `brasil-api cnpj 00000000000000 --fields razao_social,situacao`

Resultado final: uma CLI brasileira pronta pra publicar no library oficial.
