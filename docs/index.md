# Curso Printing Press 🖨️

**Aprenda a transformar qualquer site ou API em uma CLI otimizada para agentes de IA.**

> Em benchmarks oficiais: MCP consome **35× mais tokens** que CLI na mesma tarefa, e a confiabilidade cai de **100% para 72%**. CLIs são hoje a forma mais eficiente de conectar agentes (Claude Code, Codex, Gemini) a ferramentas externas.

---

## Para quem é este curso?

- Devs que usam **Claude Code** e querem reduzir consumo de tokens
- Quem mantém integrações com **n8n / Make / Supabase** e quer menos overhead
- Quem precisa integrar com sites **sem API pública** (Skool, Craigslist, sistemas internos brasileiros)
- Quem quer entender por que CLIs estão substituindo MCPs em 2026

## O que você vai aprender

1. A diferença prática entre **API, MCP e CLI** — com números reais
2. Como instalar Printing Press e usar a **biblioteca de 87+ CLIs prontas**
3. Como **criar sua própria CLI** em ~10 minutos a partir de qualquer URL ou API
4. Como **integrar com n8n** e reduzir custo de execução de fluxos
5. Como **publicar** sua CLI no catálogo oficial
